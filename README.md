# HomePlus web

The HomePlus web frontend — a digital home MOT logbook and Trade Pilot marketplace.

## Getting started

```sh
npm install
npm run dev
```

The dev server proxies `/api` to the backend at `http://127.0.0.1:8030` (see `vite.config.ts`).

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Build

```sh
npm run build
```
